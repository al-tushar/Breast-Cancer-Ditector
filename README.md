# Breast Cancer Detection AI

Machine learning and CNN models that classify breast tumors as benign or malignant,
with a desktop app (CustomTkinter) for making predictions.

## Files
- `train_model.py`: trains the CNN
- `breast_cancer_ml.py`: classical ML models
- `predict.py`: runs a prediction on an image
- `app.py`: desktop GUI

## Dataset
Not included because of its size. Download it from [https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data]
and place it in a `dataset/` folder.

## Setup
pip install -r requirements.txt
python app.py

## Disclaimer
Educational project only. Not a medical diagnostic tool.
